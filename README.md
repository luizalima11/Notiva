# Notiva 🌐

## 📌 Sobre o Projeto

O **Notiva** é um sistema web desenvolvido como trabalho acadêmico para a disciplina de **Desenvolvimento de Sistemas Web 1**, do 2º semestre do curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

A plataforma permite que os usuários compartilhem publicações, interajam com conteúdos e personalizem seus perfis.

## 🎯 Objetivo

Desenvolver uma aplicação web de interação social, aplicando os conhecimentos de desenvolvimento frontend, backend e banco de dados adquiridos durante a disciplina.

## ⚙️ Tecnologias Utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização e responsividade.
- **JavaScript:** interatividade e atualização dinâmica do conteúdo.
- **PHP:** lógica do sistema e comunicação com o banco de dados.
- **SQL:** armazenamento e gerenciamento das informações.

## 🚀 Funcionalidades

- Cadastro e login de usuários.
- Criação, edição e exclusão de publicações.
- Feed com publicações de todos os usuários.
- Atualização automática do feed a cada cinco minutos.
- Comentários nas publicações.
- Curtidas e descurtidas.
- Adição e remoção de publicações dos favoritos.
- Perfis personalizados com foto, biografia e informações adicionais.
- Visualização de publicações curtidas e favoritas.
- Configurações de tema e preferências.

## 🗄️ Banco de Dados

O banco de dados será responsável por armazenar e gerenciar as informações de usuários, publicações, comentários, curtidas, favoritos e preferências dos perfis, mantendo a integridade e a consistência dos dados.

## 📚 Finalidade

Aplicar na prática os conceitos de desenvolvimento web, integração entre frontend e backend, manipulação de banco de dados e desenvolvimento colaborativo utilizando Git e GitHub.
